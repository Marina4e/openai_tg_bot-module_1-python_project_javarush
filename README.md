Проект "Telegram/ChatGPT"

Виконанні умови:
- Проект представляє собою Telegram-бота з підключенням ChatGPT.
- У проекті реалізовані функціональності з 4 обов'язкових пунктів та 2 пунктів на вибір.
- Код проекту відповідає стандарту [PEP8](https://peps.python.org/pep-0008/)
- Код відмовостійкий
- Використовувати будь-яку бібліотеку для Telegram API

Це плюс, що у проекті є:

- Наявність файлу readme
- Наявність файлу requirements.txt
- Використання ConversationHandler
- Використання змінних середовища (для зберігання токенів)
- Логування
- Розгортання проекту на сервері (ngrok, pythonanywhere, glitch або ін.)
- Використання технологій, які не розглядалися в першому модулі

### 1. *"Випадковий факт"*
Телеграм-бот обробляє команду /random.
При обробці команди він надсилає заздалегідь підготовлене зображення
та робить запит до ChatGPT із заздалегідь підготовленим промптом.
Відповідь ChatGPT отримує та передає користувачеві.
До повідомлення прикріплена кнопка "Закінчити", натискання на яку
працює так само, як команда /start.
І кнопка "Хочу ще факт", натискання на якупрацює так само, як команда /random

### 3. *"Діалог з відомою особистістю"*
Телеграм-бот обробляє команду /talk.
При обробці команди бот надсилає заздалегідь підготовлене зображення та
пропонує вибір з декількох відомих особистостей,
використовуючи кнопки. При натисканні кнопки спрацьовує промпт обраної особистості.
Подальші текстові повідомлення від користувача передаються ChatGPT та
повертаються його відповіді користувачеві.
До них прикріплена кнопка "Закінчити", натискання на яку працює так само, як команда /start

### 4. *"Квіз"*
Телеграм-бот обробляє команду /quiz.
При обробці команди бот надсилає заздалегідь підготовлене зображення
та пропонує вибір з декількох тем, використовуючи кнопки.
Після вибору теми, передається запит ChatGPT і, отримавши питання квізу, передано
користувачеві. Наступне текстове повідомлення користувача вважається відповіддю.
Його передається ChatGPT та отримується результат. Результат передається користувачеві
з можливістю задати ще питання на ту ж тему, змінити тему або закінчити квіз, за допомогою кнопок.
Бот також веде рахунок правильних відповідей та відображає разом з черговим результатом
